# bookstore-map

모바일 서점 안내 정적 웹사이트입니다. 폴더 전체를 내려받아 압축을 풀고 `index.html`을 여세요. 이미지·제주명조 폰트는 프로젝트 내부 파일을 사용합니다.

## 서점 정보 수정

- `bookstores.js`에서 서점 정보를 수정합니다. 배열의 위에서 아래 순서가 메인 표시 순서입니다.
- 추가: 기존 서점 객체를 복사하고 중복되지 않는 `id`를 지정합니다. 삭제: 해당 객체를 지웁니다. 순서 변경: 객체 전체를 원하는 위치로 옮깁니다. HTML 수정은 필요 없습니다.
- 필수 항목: `id`, `name`(서점명), `region`(지역), `cover`(메인 사진), `photos`(팝업 사진 2~4장), `instagramUrl`, `naverMapUrl`.
- 사진을 `images` 폴더에 넣고 `images/파일명.png`처럼 상대 경로로 지정하세요. 파일명과 확장자의 대소문자까지 맞춰 주세요. 서점별 하위 폴더(`images/bubif/cover.jpg`)도 사용할 수 있습니다. 현재 샘플은 같은 사진을 공유합니다.
- `photos` 배열의 순서가 슬라이드 순서입니다. 파일이 누락되면 사진 준비 중 안내가 표시되며, 다음 사진으로 이동할 수 있습니다. 메인 사진 누락 시 배경색과 서점 정보는 유지됩니다.
- 링크는 실제 `https://` 주소를 입력합니다. 주소가 없다면 `null`로 두세요. 비어 있거나 잘못된 주소는 비활성화됩니다.
- 선택 항목 `position`은 메인 사진의 크롭 위치입니다(기본값: 중앙). `detailName`은 팝업에서만 다른 이름을 표시할 때 사용하며, 생략하면 `name`을 표시합니다.
- 인스타그램 대신 웹사이트를 연결하려면 `instagramUrl`을 `null`로 두고 선택 항목 `websiteUrl`에 주소를 입력하세요. 버튼명이 웹사이트로 바뀝니다.
- 현재 19곳은 제공된 폴더 번호순으로 등록되어 있습니다. 메인은 각 폴더의 `thumb`, 팝업은 나머지 사진을 사용합니다. 상세 사진이 1장만 제공된 서점은 그 1장을 표시하며 이동 버튼을 숨깁니다.
- 지역 정보는 자료에 없어 빈 문자열로 두었습니다. 부비프 인스타그램은 아인서점과 중복된 주소로 전달되어 확인 전까지 비활성화했으며, 아인서점의 네이버지도는 미제공 상태입니다.

## 로컬 서버로 확인

프로젝트 폴더에서 `python3 -m http.server 8000`을 실행하고 같은 컴퓨터의 브라우저로 접속할 수도 있습니다. 별도 패키지 설치는 필요 없습니다.
